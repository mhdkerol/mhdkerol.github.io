About

From reporting to the data behind it

I've worked in data for around three years, starting as a Data Analyst in online retail and now as a Senior Data Associate in B2B marketing, where I provide backend data support for client accounts.

In my current role I work with campaign and CRM data. I clean and prepare exports with Python, load them into the reporting database, validate each load against the source files, and troubleshoot data issues with SQL.

Before that, I built the Google Sheets reporting backends and Looker Studio dashboards that management used to track sales and inventory.

These experiences strengthened my interest in the engineering behind reliable reporting: transforming raw data into structured, well-modelled datasets that people can depend on.

Alongside my job I build data projects with Python, SQL, dbt and BigQuery, covering ingestion, transformation, data modelling, testing and automation.

Featured project

Data pipeline · Analytics engineering

YouTube Marketing Analytics Pipeline

An automated pipeline that collects YouTube data on marketing content across 30 keywords (videos, channels, comments and positions in YouTube search results), stores the raw API responses in Google Cloud Storage, and models them with dbt in BigQuery. The final tables feed a Looker Studio dashboard.

  • Scheduled weekly on GitHub Actions, from ingestion to tested tables
  • Bronze, silver and gold layers, ending in a star schema
  • Channel history kept with a dbt snapshot (SCD Type 2)
  • dbt tests and freshness checks run before the final tables are built

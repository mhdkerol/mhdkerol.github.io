YouTube Marketing Analytics

An automated system that collects data on marketing videos from YouTube every week, cleans and checks it, and feeds a dashboard showing which videos and channels perform best.

The question

Which marketing videos on YouTube get the most engagement, and how are channels growing over time?

What I built

A weekly pipeline that tracks 30 marketing topics, stores every run so history is never lost, and runs automatic quality checks before anything reaches the dashboard.

How it works

1 · COLLECTPull video, channel and comment data from YouTube
2 · STORESave the raw data in the cloud, untouched
3 · CLEAN & CHECKRemove duplicates, fix types, run 56 quality tests
4 · REPORTShow the results in an interactive dashboard

Runs automatically every week. If a check fails, it stops and sends an email alert.

About

From reporting to the data behind it

I've worked in data for about three years, first as a Data Analyst in online retail and now as a Senior Data Associate in B2B marketing, where I provide backend data support for client accounts.

A lot of my work is getting data into a correct, usable state. I clean campaign and CRM exports with Python, load them into the reporting database, check each load against the source files, and use SQL to track down and fix data issues. In my previous role I built the Google Sheets backends and Looker Studio dashboards that management used for sales and inventory reporting.

Over time I've found that the part I care about most comes before the dashboard: getting raw data into clean, well-modelled tables that people can rely on. That's where I'm taking my career, toward analytics engineering and data engineering.

Outside work I build projects to practise this end to end, from ingestion to modelling, testing and automation. The code is on GitHub.

Featured project

Data pipeline · Analytics engineering

YouTube Marketing Analytics Pipeline

An automated pipeline that collects YouTube data on marketing content (videos, channels, comments and search rankings for 30 marketing keywords), stores the raw data in Google Cloud Storage, transforms it with dbt in BigQuery, and feeds a performance dashboard in Looker Studio.

  • Ran weekly on GitHub Actions, from ingestion to tested tables
  • Bronze, silver and gold layers, ending in a star schema
  • Channel history kept with a dbt snapshot (SCD Type 2)
  • dbt tests and freshness checks run before the final tables are built
